Automation and bulk forms

This static site supports people and browser-driving agents through the same trusted template, validation, and printing workflow.

Local JSON and CSV files are processed in your browser and are not uploaded by this workflow. Data shared with an external AI service is still subject to that service's data-handling policy.

Form codes are exact rather than fuzzy. Matching ignores case, spaces, and hyphens. An exact version makes a link reproducible.

If a code has multiple trusted versions and no version is supplied, the site reports an ambiguity instead of guessing.

Create records in bulk

  1. Open the form and choose Bulk CSV, or use ?template=FORM100&version=2026.1&action=bulk-csv.
  2. Keep the machine-readable headers in row 1 unchanged.
  3. Use the labels in row 2 and examples in row 3 as guidance. Those reference rows are ignored during import.
  4. Add one completed record per subsequent row using only known facts.
  5. Return to the same form, choose Print CSV, and select the completed CSV.
  6. After validation and rendering, choose Save as PDF in the normal print dialog.

Do not invent signatures, acknowledgments, incidents, ratings, or dates. Conditional forms may require values that select the applicable layout before its related fields are accepted.

Limits and automation

Batches over 1,000 records require confirmation because large batches may consume substantial memory or make the browser unresponsive. ZIP downloads are limited to 65,535 submissions.

Browser automation can monitor html[data-app-state] for loading, rendering, downloading, ready, or error.

URLs cannot select a local file automatically, and plain HTTP clients do not execute browser actions. This MVP does not provide HTTP upload, conversion, or PDF-rendering endpoints.
